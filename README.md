# Monte Carlo Statistical Simulations in R

A collection of computational statistics and stochastic modeling scripts developed during the Probability and Statistics coursework at Instituto Superior Técnico (IST).

---

## Overview
This repository applies Monte Carlo simulation methods to empirically analyze classical probabilistic paradoxes and evaluate asymptotic convergence behaviors where analytical solutions benefit from numerical validation.

---

## Features
- **Vectorized Monte Carlo Engine:** High-throughput matrix evaluation simulating $N = 20,000$ trials across sample spaces.
- **Reproducibility:** Seed control (`set.seed(1006)`) ensuring deterministic, verifiable numerical results.
- **Empirical Probability Estimation:** Evaluates collision probabilities (e.g., the Birthday Paradox formulation) across variable group sizes.

---

## Tech Stack
- **Language:** R
- **Environment:** RStudio
- **Key Concepts:** Stochastic modeling, pseudo-random generation, vectorized matrix computation
